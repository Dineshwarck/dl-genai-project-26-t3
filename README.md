# SurfaceGuard AI: Industrial Surface Anomaly Segmentation

## Project Overview

SurfaceGuard AI is a deep learning-based system for automatic anomaly detection on industrial surfaces using image segmentation. The project focuses on training a U-Net architecture to identify defects or anomalies in metal surfaces, achieving high precision and recall scores.
